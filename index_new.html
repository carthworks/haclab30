Course Overview

30-Day Ethical Hacking Bootcamp

Daily modules, labs, quizzes and a final capstone.

Details

Duration: 30 days (3–4 hrs/day suggested)

Format: Pre-recorded lessons, guided labs, weekly live Q&A, capstone.

Day 1-2: Learn Linux Commands
Goals
  • Install Ubuntu/Kali
  • Basic shell navigation, file ops, permissions
Lab
  • File tasks, SSH simulation
Day 3-4: Networking Basics
  • TCP/IP, DNS, ports
  • Tools: ping, netstat, traceroute
Lab
  • Wireshark basics, network mapping
Day 5-7: OWASP Top 10
  • Overview of OWASP Top10
  • Hands-on XSS/SQLi labs (DVWA/Juice Shop)

Day 8-9: Nmap
  • Scan types, host discovery
  • Lab: scan & enumerate services
Day 10-11: Burp Suite
  • Proxy, intercept, modify requests
  • Lab: brute-force and analyze requests
Day 12-13: Metasploit
  • Exploit basics
  • Lab: controlled exploitation on vulnerable VM

Day 15-16: SQLmap
  • SQLi concepts
  • Lab: extract data from DVWA
Day 17-18: TryHackMe/HTB Labs
  • Hands-on challenge solving
  • Assignment: lab report
Day 19-20: Community & Networking
  • How to join & contribute
  • Share writeups & build presence

Day 21-23: Vulnerability Research
  • Track CVEs, feeds, blogs
  • Lab: simulate new CVE
Day 24-26: Final Lab
  • Recon → Exploit → Report
  • Use all tools learned
Day 27: Reporting & Ethics
  • Write professional pentest reports
  • Responsible disclosure process

Day 29: Recap & Mock Test
  • Full review
  • Mock test (theory + practical)
Day 30: Final Exam & Certificate
  • Online practical exam
  • Certificate issuance

Day 31-32: AI Threat Detection
  • Intro to ML for anomaly detection
  • Lab: simple model to flag suspicious traffic
Day 33-34: n8n Automation
  • Create security workflows (alerts → ticket)
  • Lab: parse scanner results & draft finding
Included
  • Downloadable cheat-sheets
  • Lab guides
  • Community & mentors
  • Certificate
